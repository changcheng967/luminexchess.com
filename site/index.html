    2. Method

    Measured, not guessed

    Luminex runs its own OpenBench instance. A candidate change plays the current engine until a sequential probability ratio test can tell a gain from noise.

    1. 1

      Pull request

      Each change comes with the mechanism it relies on and how it was checked.

    2. 2

      Seven builds

      Continuous integration compiles every target on Linux, Windows and macOS.

    3. 3

      SPRT

      Games at 10+0.1 against the current engine, until the test accepts a gain between 0 and 5 Elo or rejects it.

    4. 4

      Merge

      A pass merges. Results inside the error margin are decided openly, numbers in the commit.

    3. Inside the engine

    Two evaluations, one search

    Luminex pairs a quantized neural network with a hand-crafted fallback, behind a search built from the techniques that define modern engines.

    2 × 76816321

    A network that follows the pieces

    A 768-wide neural network scores every position. A move changes only a few of its inputs, so the first layer is updated with a few additions instead of being computed again. In training, the newest network has been shown about 117 billion positions.

    best linereducedpruned

    A search that knows where to look

    Alpha-beta search that orders its moves, searches the best guess in full, reduces the late ones and prunes what cannot matter, so the time goes where the game is decided.

    1,157,611

    nodes per second, one thread

    More than a million positions a second

    From the starting position, on one thread of a Xeon Platinum 8562Y+ with AVX-512 VNNI, built from main. Speed is strength at fast time controls.

    4. Chronicle

    From first commit to 3255

    Nine months and 1,704 commits, from a handcrafted engine to a neural one, and every step since November measured on OpenBench.

    1. Jan 2026

      First commit

      27 January: a handcrafted evaluation and an alpha-beta search.

    2. Apr 2026

      Version 5

      The evaluation is rewritten from scratch (v5.0, 9 April), then tuned release by release.

    3. Jul 2026

      The first network

      12 July: Luminex plays with an NNUE for the first time. SIMD work then takes the network from 81,000 to 982,000 nodes per second.

    4. Aug 2026

      The handcrafted peak ≈2500

      Tuned by distillation, the classical evaluation reaches about 2500 on the Stash ladder (v5.16).

    5. Sep 2026

      gen768 ≈2800

      A 768-wide network becomes the default and NNUE is switched on for everyone (v6.1).

    6. Oct 2026

      3000 crossed ≈3030

      v6.3 ships a network trained on Leela positions labeled by Stockfish, with the loss weighted toward quiet positions.

    7. Nov 2026

      OpenBench, then v6.4

      Every change now passes an SPRT on a pool of Xeon workers. v6.4 ships the first week of them: the network loads by itself, and every download is built for the CPUs its name promises.

    8. Nov 2026

      v6.5 ≈3255

      A day of search work, each change through an SPRT: history that learns from failed moves, a hash table that keeps its best move, leaner extensions. +145 Elo over v6.4, and Stash 32 beaten. v6.5.1 puts the network inside every download.

    9. Nov 2026

      Time, measured

      On main since v6.5.1: a time schedule solved from the measured value of time, +72 Elo at 10+0.1 and +37.5 at CCI's 60+0.6, and a stop rule from best-move stability, +8.3. Two SPSA runs of 80,000 games each retune the search constants.

    10. Nov 2026

      Eight output buckets +54.5

      gen768r_03: eight output buckets, revived tail neurons and 2.5 billion T91 positions, +54.5 Elo against the released network in self-play. A third SPSA run retuned the search constants for it, and network and constants went into main together.

    11. Nov 2026

      Trained through its own rounding +13.4

      gen768r_03q: the same network trained on to 460,000 steps, then 30,000 steps of quantization-aware training, which trains through the engine's int8 rounding. +13.4 Elo against gen768r_03, which it replaced on main.

    12. Nov 2026

      Development builds

      Every push to main that passes its checks now publishes a development build, which replaces the one before. Against v6.5.1, main with gen768r_03q scored +202, +179 and +173 Elo in self-play at CCI's three time controls.

    13. Nov 2026

      More positions, more steps +13.3

      gen768r_04q: the same run continued to 860,000 steps, now on 3.73 billion positions and with a loss power of 3.0 instead of 2.6, then 30,000 quantization-aware steps. +13.3 Elo against gen768r_03q, and now the network on main.

    14. Nov 2026

      Rated against twelve engines 3448

      Gauntlets on OpenBench now rate a build against other engines. The first full one: main with gen768r_04q, 9,612 games at 10+0.1 against twelve engines rated from 3417 to 3773. 3448 ± 24 on the CCRL Blitz scale, and 57.5% against Stash 37.

    15. Next

      The next release

      A retune of 13 search margins for the new network moved none of them beyond noise, so the margins stay as they are. The release brings the new network, the retuned search constants and the time management work. In design for the one after: gen768s, a network that also estimates its own error.
